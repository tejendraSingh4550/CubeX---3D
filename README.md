# CubeX

A responsive Rubik’s cube playground built with Angular standalone components and Three.js.

## Features

- Interactive, orbitable 3D 3×3×3 cube with zoom
- U, D, L, R, F, B turns and inverse turns (Shift + key, or right-click the cube)
- Scramble, undo, reset, and solve by reversing recorded moves
- Session timer, move counter, and move history
- Responsive dark interface and keyboard shortcuts

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI (usually http://localhost:4200). To create a production build, run `npm run build`.
